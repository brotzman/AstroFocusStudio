AstroFocus Studio 3.9.0 – GitHub-Upload

1. ZIP vollständig entpacken.
2. Auf GitHub ein leeres Repository ohne automatisch erzeugte Dateien anlegen.
3. Den gesamten Inhalt einschließlich des versteckten Ordners .github committen.
4. Auf den Branch main pushen.
5. Unter GitHub Actions den Workflow "Build and test Windows installer" abwarten.
6. Das fertige Paket aus dem Artifact "AstroFocusStudio-3.9.0-Windows-x64" laden.

Ausführliche Anleitung: docs/GITHUB_UPLOAD_DE.md

Hinweis zum GitHub-Webupload:
Der Workflow startet Shellskripte ausdrücklich über bash. Dadurch funktioniert der
Sanitizer-Lauf auch dann, wenn der Webupload das Unix-Ausführungsbit nicht bewahrt.
Für reguläre Weiterentwicklung wird dennoch ein Upload per git commit/push empfohlen.

Release manuell veröffentlichen:
1. Actions → "Build and test Windows installer" → Run workflow öffnen.
2. publish_release aktivieren.
3. release_tag auf v3.9.0 belassen.
4. Workflow starten. Erst nach allen erfolgreichen Tests werden Tag und Release erstellt.

Der MSI- und Setup-Installer legt automatisch "AstroFocus Studio" auf dem öffentlichen Desktop an.
